1. Que es VISNEX

Vision del proyecto

VISNEX es una plataforma SaaS (Software as a Service) de dropshipping automatizado. Permite a un emprendedor encontrar productos en proveedores internacionales, enriquecerlos con inteligencia artificial (descripciones, SEO, imagenes) y publicarlos automaticamente en una tienda online con estetica premium estilo Apple.

El nombre viene de Vision + Nexus: la vision de conectar proveedores globales con tiendas locales de forma automatizada.

Para quien es

  • Emprendedores que quieren vender en internet sin tener inventario propio.
  • Negocios existentes que quieren ampliar su catalogo con productos de dropshipping.
  • Personas que quieren una tienda online profesional sin conocimientos tecnicos avanzados.

Que problema resuelve

El dropshipping tradicional requiere:

  1. Buscar productos manualmente en proveedores (CJ Dropshipping, AliExpress, etc.).
  2. Copiar y pegar informacion del producto (titulo, descripcion, precio, imagenes).
  3. Calcular precios manualmente (costo + envio + arancel + IVA + margen).
  4. Escribir descripciones atractivas en espanol.
  5. Subir todo a la tienda online uno por uno.

VISNEX automatiza TODO este proceso. Importas un CSV o buscas en APIs de proveedores, la IA enriquece el producto y con un click se publica en tu tienda WordPress/WooCommerce.

VISNEX no es solo una herramienta: es un sistema completo con backend en microservicios, panel de administracion, tienda publica y motor de inteligencia artificial.

Bases de datos

VISNEX usa dos motores de base de datos:

  • PostgreSQL (puerto 5433): Para todos los microservicios del backend. Cada servicio tiene su propia base de datos separada (auth_db, admin_db, etc.).
  • MySQL (puerto 3307): Exclusivamente para WordPress/WooCommerce. WordPress requiere MySQL.

Como se comunican los servicios

  1. El frontend envia peticiones HTTP al gateway (puerto 8841).
  2. El gateway revisa el JWT (token de seguridad) y enruta la peticion al microservicio correcto.
  3. Los microservicios se encuentran entre si gracias a Eureka (discovery-service).
  4. Cuando un servicio necesita hablar con otro (ej: acquisition necesita datos de administration), lo hace a traves de llamadas HTTP internas usando el nombre registrado en Eureka.
  5. El commerce-service se comunica con WordPress usando la API REST de WooCommerce para publicar productos.
Todos los microservicios usan el context path /vn-api. Ejemplo: http://localhost:8841/vn-api/v2/company/all

3. Como levantar el proyecto

Requisitos previos

Antes de empezar, necesitas tener instalado en tu computadora:

Java JDK17Lenguaje del backendjava --version
Apache Maven3.8+Compila los proyectos Javamvn --version

Git2.xControl de versiones del codigogit --version
Docker Desktop necesita al menos 8 GB de RAM asignados. Si tienes 16 GB de RAM total, asigna al menos 8 GB a Docker. Ve a Docker Desktop > Settings > Resources > Memory.

Paso 1: Clonar el repositorio

git clone https://github.com/tu-usuario/dropshipping.git
cd dropshipping

Paso 2: Compilar el backend

Esto compila todos los microservicios Java y genera los archivos .jar necesarios:

cd backend
mvn clean package -DskipTests
cd ..

Este proceso tarda entre 2-5 minutos la primera vez. Maven descargara las dependencias automaticamente.

Paso 3: Levantar todo con Docker

Un solo comando levanta TODO: bases de datos, microservicios, WordPress y frontend:

docker-compose --env-file ./backend/.env up --build -d

La primera vez tardara entre 5-15 minutos porque Docker descarga imagenes base (Java, PostgreSQL, MySQL, WordPress, Node.js).

Si solo necesitas levantar parte del sistema, puedes usar comandos parciales: 
# Solo infraestructura (bases de datos + Eureka + Gateway)
docker-compose -f docker-compose.infra.yml --env-file ./backend/.env up --build -d

# Solo WordPress
docker-compose -f docker-compose.wp.yml up --build -d

# Solo frontend
docker-compose -f docker-compose.frontend.yml up --build -d

Paso 4: Verificar que todo funciona

Espera 2-3 minutos despues de levantar Docker y luego verifica cada componente:

ComponenteURL de verificacionQue debes ver
Eureka (Discovery)http://localhost:8840Panel Eureka con los servicios registrados
Gatewayhttp://localhost:8841/actuator/health{"status":"UP"}
Frontend (Panel)http://localhost:3001Pantalla de login de VISNEX
WordPress (Tienda)http://localhost:8850Tienda WordPress funcionando
phpMyAdminhttp://localhost:8851Interfaz de phpMyAdmin

Paso 5: Ver logs si algo falla

# Ver logs de todos los servicios
docker-compose logs -f

# Ver logs de un servicio especifico
docker-compose logs -f auth-service
docker-compose logs -f commerce-service

# Ver estado de los contenedores
docker-compose ps

Comandos utiles

# Detener todo
docker-compose down

# Detener y borrar volumenes (BORRA datos de las bases de datos)
docker-compose down -v

# Reconstruir un servicio especifico
docker-compose up --build -d commerce-service

# Compilar solo un servicio Java
cd backend && mvn clean package -pl commerce-service -DskipTests

5. Flujo de trabajo completo

Esta seccion explica paso a paso como usar VISNEX, desde el login hasta ver un producto publicado en la tienda. Sigue cada paso en orden.

Login → Proveedor → Importar CSV → Enviar a Commerce → Precios → IA → Enriquecer → Publicar → Tienda
5.1 Login - Iniciar sesion

Donde ir

Abre tu navegador y ve a http://localhost:3001

Que veras

Una pantalla de login con el logotipo VISNEX, dos campos (email y contrasena) y un boton "Iniciar Sesion".

Que hacer

  1. En el campo Email, escribe: admin@visnex.co
  2. En el campo Contrasena, escribe: admin123
  3. Click en "Iniciar Sesion"

Que pasa despues

El sistema valida tus credenciales contra el auth-service. Si son correctas, te genera un token JWT (un codigo de seguridad temporal) y te redirige al Dashboard.

El Dashboard es la pagina principal del panel. Desde aqui puedes navegar a todas las secciones usando el menu lateral izquierdo.

El token JWT dura 10 dias. Despues de ese tiempo tendras que volver a iniciar sesion. El token se almacena en el navegador automaticamente.

5.3 Importar productos desde CSV

Que es un CSV

Un CSV (Comma Separated Values) es un archivo de texto simple que contiene datos en formato de tabla. Puedes exportar CSVs desde Excel, Google Sheets o directamente desde proveedores como CJ Dropshipping.

Como llegar

Menu lateral → Fuentes → Importar

Pasos

  1. Seleccionar proveedor: Elige el proveedor al que pertenecen estos productos (ej: CJ Dropshipping).
  2. Subir archivo: Arrastra tu archivo CSV al area de carga, o click en "Seleccionar archivo".
  3. Deteccion de columnas: El sistema lee las cabeceras del CSV y las muestra en una tabla de mapeo.
  4. Mapear columnas: Para cada campo del sistema, selecciona la columna correspondiente del CSV:
    Campo VISNEXColumna CSV (ejemplo)
    Nombre del productoProduct Name o Title
    SKUSKU o Item Code
    Precio costoPrice o Cost
    DescripcionDescription
    URL imagenImage URL
    CategoriaCategory
    Peso (kg)Weight
  5. Vista previa: El sistema muestra las primeras filas procesadas para que verifiques que todo esta correcto.
  6. Ejecutar importacion: Click en "Importar". Veras una barra de progreso.
  7. Resultado: Al terminar, veras un resumen: cuantos productos se importaron, cuantos fueron omitidos (duplicados o con errores) y cuantos fallaron.
Los productos importados quedan en el acquisition-service. Aun no estan en tu catalogo de comercio. El siguiente paso es enviarlos a Commerce.
5.4 Enviar productos a Commerce

Que significa "enviar a Commerce"

Los productos importados viven en el modulo de Fuentes (acquisition-service). Para trabajar con ellos (precios, IA, publicacion), necesitas enviarlos al modulo de Productos (commerce-service).

Como llegar

Menu lateral → Fuentes → Buscar

Pasos

  1. Veras la lista de todos los productos importados.
  2. Puedes filtrar por proveedor, categoria o buscar por nombre.
  3. Selecciona los productos que quieres enviar (checkboxes a la izquierda).
  4. Click en "Enviar a Commerce".
  5. El sistema copia los datos del producto al commerce-service.
  6. El producto aparece ahora en Productos → Lista con estado DRAFT.
DRAFT significa "borrador". El producto existe en tu catalogo pero no esta listo para publicarse. Primero hay que enriquecerlo con IA y configurar precios.

5.6 Configurar IA

Donde configurar

Menu lateral → IA → Configuracion

Pasos

  1. Seleccionar proveedor de IA:
    • OpenAI (GPT-4, GPT-3.5) - El mas popular, requiere API key de pago.
    • Claude (Anthropic) - Alta calidad, requiere API key de pago.
    • Ollama - Gratuito, corre en tu computadora local (requiere instalar Ollama).
  2. Ingresar API Key: Pega la clave API del proveedor seleccionado.
    • Para OpenAI: Ve a platform.openai.com → API Keys → Crear nueva.
    • Para Claude: Ve a console.anthropic.com → API Keys.
    • Para Ollama: No necesita API key (es local).
  3. Seleccionar modelo: Elige que modelo especifico usar (ej: gpt-4o, claude-3-sonnet, llama3).
  4. Presupuesto mensual: Define un limite de gasto mensual en USD. Cuando se alcanza, la IA deja de funcionar hasta el proximo mes.
  5. Click en "Guardar configuracion".
Sin una configuracion de IA valida, no podras enriquecer productos. Ollama es la opcion gratuita si no quieres pagar API keys.
5.7 Enriquecer producto con IA

Que es "enriquecer"

Enriquecer un producto significa usar inteligencia artificial para mejorar su informacion: generar un titulo atractivo, una descripcion profesional, puntos clave (bullets), palabras clave SEO y textos alternativos para imagenes.

Como llegar

Menu lateral → Productos → Lista

Pasos

  1. Busca un producto con estado DRAFT.
  2. Click en el boton "Enriquecer con IA" (icono de varita magica o similar).
  3. El sistema envia los datos del producto al proveedor de IA configurado.
  4. Espera unos segundos. La IA genera:
    • Titulo mejorado: Mas atractivo y con palabras clave.
    • Descripcion completa: Texto profesional de venta en espanol.
    • Bullet points: 3-5 puntos clave del producto.
    • SEO: Meta titulo, meta descripcion, slug optimizado.
    • Alt text: Texto descriptivo para las imagenes (accesibilidad + SEO).
  5. Puedes revisar y editar lo que genero la IA antes de aceptar.
  6. Click en "Aceptar enriquecimiento".
  7. El producto cambia de estado DRAFT → ENRICHED.
Puedes re-enriquecer un producto tantas veces como quieras. Cada vez genera contenido nuevo (y consume creditos de la API de IA).
5.8 Publicar a WordPress

Que significa publicar

Publicar toma un producto ENRICHED y lo crea en tu tienda WordPress/WooCommerce. Esto incluye titulo, descripcion, precio, imagenes, categorias, tags y SEO.

Como llegar

Menu lateral → Productos → Lista

Pasos

  1. Busca un producto con estado ENRICHED.
  2. Click en el boton "Publicar" (icono de nube o flecha hacia arriba).
  3. El sistema usa la API REST de WooCommerce para:
    • Crear el producto en WordPress.
    • Subir las imagenes con alt text.
    • Asignar categorias y tags.
    • Configurar el precio calculado en COP.
    • Establecer los datos de SEO (meta titulo, meta descripcion).
  4. El producto cambia de estado ENRICHED → PUBLISHED.
  5. Veras un enlace directo al producto en la tienda.
Puedes publicar productos en lote (seleccionando varios y click en "Publicar seleccionados") o uno por uno.
5.9 Ver en la tienda

Como ver el producto publicado

  1. Abre tu navegador en http://localhost:8850
  2. Navega a la seccion de "Tienda" o usa el buscador.
  3. Veras tu producto con:
    • Titulo enriquecido por IA.
    • Descripcion profesional en espanol.
    • Imagenes del proveedor.
    • Precio en COP calculado automaticamente.
    • SEO optimizado (visible en el codigo fuente).

Tambien puedes acceder al admin de WordPress en http://localhost:8850/wp-admin para ver el producto desde el panel de WooCommerce.

Es la pagina de inicio. Muestra un resumen general de la plataforma: metricas, actividad reciente y accesos rapidos.

Como llegar

Se muestra automaticamente despues del login. Tambien puedes hacer click en "Dashboard" en el menu lateral.

Que se puede hacer

  • Ver actividad reciente (ultimas importaciones, publicaciones).

7. Estados de un producto

Cada producto en VISNEX pasa por un ciclo de vida con estados bien definidos. Los estados controlan que acciones se pueden realizar sobre el producto.

DRAFT → ENRICHED → PUBLISHED → ARCHIVED
EstadoSignificadoComo llega aquiAcciones disponibles
DRAFT Borrador. El producto fue importado pero no tiene contenido enriquecido. Tiene los datos crudos del proveedor. Se crea automaticamente cuando envias un producto desde Fuentes a Commerce. Editar, Enriquecer con IA, Eliminar.
ENRICHED Enriquecido. La IA genero titulo, descripcion, SEO y bullets. El producto esta listo para publicar. Despues de aceptar el enriquecimiento con IA. Editar, Re-enriquecer, Publicar, Archivar.
PUBLISHED Publicado. El producto esta visible en la tienda WordPress/WooCommerce. Los clientes pueden verlo y comprarlo. Despues de publicar exitosamente a WordPress. Editar, Actualizar en tienda, Despublicar, Archivar.
ARCHIVED Archivado. El producto esta oculto. No aparece en la tienda ni en las listas principales. Se puede reactivar. Cuando decides retirar un producto del catalogo activo. Reactivar (vuelve a ENRICHED o DRAFT).

Transiciones permitidas

DRAFT      --[Enriquecer con IA]-->  ENRICHED
ENRICHED   --[Publicar]----------->  PUBLISHED
PUBLISHED  --[Despublicar]-------->  ENRICHED
ENRICHED   --[Archivar]----------->  ARCHIVED
PUBLISHED  --[Archivar]----------->  ARCHIVED
ARCHIVED   --[Reactivar]---------->  DRAFT o ENRICHED
ENRICHED   --[Re-enriquecer]------>  ENRICHED (mismo estado, nuevo contenido)
Un producto en estado DRAFT no se puede publicar directamente. Siempre debe pasar por ENRICHED primero.

8. Configuracion de precios

Que es cada campo

CampoTipoDescripcion detallada
Costo del productoUSDEl precio que cobra el proveedor por el producto. Se toma directamente del CSV importado o de la API del proveedor.
Costo de envioUSDLo que cobra el proveedor por enviar el producto desde su pais (normalmente China) hasta Colombia. Varia segun peso y tamano.
Arancel%Impuesto de importacion que cobra la aduana colombiana. Varia segun el tipo de producto (15-20% es comun para electronica y accesorios).
IVA%Impuesto sobre el Valor Agregado. En Colombia es el 19% para la mayoria de productos.
Comision plataforma%Porcentaje que cobra VISNEX como servicio. Configurable segun el plan.
Margen de ganancia%El beneficio que quieres obtener como vendedor. Tipicamente 30-60% dependiendo del nicho.
Tasa de cambioCOP/USDCuantos pesos colombianos vale un dolar. Se puede actualizar manualmente o configurar actualizacion automatica.

Formula de calculo

PASO 1: Costo base
  costo_base = costo_producto + costo_envio

PASO 2: Aplicar arancel
  subtotal_1 = costo_base * (1 + arancel/100)

PASO 3: Aplicar IVA
  subtotal_2 = subtotal_1 * (1 + iva/100)

PASO 4: Aplicar comision plataforma
  subtotal_3 = subtotal_2 * (1 + comision/100)

PASO 5: Aplicar margen de ganancia
  precio_usd = subtotal_3 * (1 + margen/100)

PASO 6: Convertir a COP
  precio_cop = precio_usd * tasa_cambio

Ejemplo numerico completo

Supongamos que importas unos audifonos bluetooth:

PasoOperacionResultado
Costo producto-$8.50 USD
Costo envio-$3.20 USD
Costo base$8.50 + $3.20$11.70 USD
+ Arancel (15%)$11.70 x 1.15$13.46 USD
+ IVA (19%)$13.46 x 1.19$16.01 USD
+ Comision (5%)$16.01 x 1.05$16.81 USD
+ Margen (40%)$16.81 x 1.40$23.54 USD
x Tasa de cambio$23.54 x 4,200$98,868 COP

El producto se publicaria en la tienda a aproximadamente $99,000 COP (redondeado).

Puedes ajustar el precio final de cada producto individualmente despues de que la formula lo calcule. La formula es solo el punto de partida.

9. WordPress y WooCommerce

Que es WordPress en este contexto

WordPress es el sistema que genera la tienda visible al publico. Es lo que ven tus clientes cuando visitan tu sitio web. VISNEX no reinventa la tienda online: usa WordPress porque es el CMS mas popular del mundo (43% de todos los sitios web) y tiene un ecosistema enorme de temas y plugins.

Que es WooCommerce

WooCommerce es un plugin de WordPress que lo convierte en una tienda online completa. Agrega funcionalidad de: productos, carrito de compras, checkout, pagos, envios, impuestos, cupones, reportes, etc. Es gratuito y es la solucion de ecommerce mas usada del mundo.

Como se conectan VISNEX y WordPress

  1. El commerce-service (backend Java) tiene las API keys de WooCommerce.
  2. Cuando publicas un producto desde el panel VISNEX, el commerce-service hace llamadas HTTP a la API REST de WooCommerce.
  3. La API REST de WooCommerce recibe los datos y crea el producto en WordPress.
  4. WordPress genera la pagina del producto automaticamente con su tema instalado.
Panel VISNEX  --[Click Publicar]-->  commerce-service  --[WooCommerce REST API]-->  WordPress
(Frontend)                          (Java/Spring)                                  (PHP/MySQL)

API Keys de WooCommerce

Las API keys son credenciales que permiten a VISNEX comunicarse con WooCommerce de forma segura. Se componen de:

  • Consumer Key (ck_...): Identifica quien hace la peticion.
  • Consumer Secret (cs_...): Contrasenya secreta que autentica la peticion.

Estas keys se configuran en el archivo backend/.env y se pasan como variables de entorno al commerce-service via Docker.

Que crea VISNEX en WooCommerce

Cuando publicas un producto, VISNEX crea en WooCommerce:

  • Producto simple: Con titulo, descripcion corta y larga, precio en COP.
  • Imagenes: Se descargan del proveedor y se suben a WordPress con alt text optimizado para SEO.
  • Categorias: Se crean automaticamente si no existen.
  • Tags: Palabras clave generadas por la IA.
  • SEO: Si tienes Yoast SEO instalado, se configuran meta titulo y meta descripcion.
  • Atributos: Color, talla, material, etc. si el producto los tiene.

11. Seguridad

JWT - Como funciona la autenticacion

JWT (JSON Web Token) es el mecanismo que usa VISNEX para saber quien eres sin tener que pedir tu contrasena en cada peticion.

Flujo de autenticacion

  1. Tu haces login con email + contrasena.
  2. El auth-service verifica tus credenciales contra la base de datos.
  3. Si son correctas, genera un token JWT (una cadena de texto larga y encriptada).
  4. El token se almacena en el navegador.
  5. En cada peticion siguiente, el navegador envia el token automaticamente en la cabecera HTTP.
  6. El gateway-service valida el token antes de enviar la peticion al servicio destino.
  7. Si el token es invalido o expiro, se redirige al login.
Login                         Peticiones posteriores
------                        -----------------------
[Email+Pass] --> auth-service   [Token JWT] --> gateway --> valida --> servicio
                    |                                |
              genera JWT                     si invalido --> 401 (no autorizado)
                    |
              devuelve token

Estructura del token JWT

Un token JWT tiene 3 partes separadas por puntos:

  • Header: Tipo de token y algoritmo de encriptacion.
  • Payload: Datos del usuario (id, email, roles, empresa, sucursal).
  • Signature: Firma digital para verificar que el token no fue alterado.

Roles y permisos

VISNEX tiene un sistema de roles configurables:

RolPermisos tipicos
AdministradorAcceso total: empresa, usuarios, productos, IA, publicacion, configuracion.
OperadorImportar productos, enriquecer, publicar. No puede configurar empresa ni usuarios.
ViewerSolo lectura. Puede ver productos, estadisticas y logs. No puede modificar nada.

Los permisos se configuran por pagina en Admin → Tipos de Usuario → Paginas.

Encriptacion

  • Contrasenas: Se almacenan encriptadas con BCrypt (hash irreversible). Nadie puede ver la contrasena original.
  • JWT Secret: La clave para firmar tokens es visnex@secret.key en desarrollo. En produccion se usa una clave mucho mas larga y segura.
  • HTTPS: En produccion, toda la comunicacion va encriptada con SSL/TLS.
  • CORS: El gateway solo acepta peticiones desde origenes autorizados (el frontend).
